【主題 2 常見的酸】

  1. 硫酸 (H₂SO₄)：
    • 無色油狀、腐蝕性強，密度比水。
    • 老師的話：沸點、難揮發，可利用此特性來製備的酸（如鹽酸、硝酸）。
    • 濃硫酸具有很強的性，可使碳水化合物脫水，形成黑色的。(如滴在方糖或紙張上會變黑)。
    • 有「」稱號，常用於製造肥料及的電解液。
    • 稀釋安全：溶於水中會放出大量。稀釋時，必須將沿杯壁慢慢加入中，並攪拌。不可反向操作，以免水沸騰濺出。
  2. 鹽酸 (HCl)：
    • 是氣體溶於水形成的水溶液，無色且具味。補充：工業用鹽酸因含有，而略呈色。
    • 打開濃鹽酸瓶蓋時，揮發出的氣體與水蒸氣結合，會形成肉眼可見的白色。
    • 可用來清洗金屬表面或作為浴廁清潔劑。警告：不可與混用，會產生有毒氣體。
    • 清洗大理石時需小心，因大理石成分為，會與鹽酸反應產生。
    • 檢驗法：遇到會結合產生白色的固體微粒 (形成白煙)。
  3. 硝酸 (HNO₃)：
    • 國防工業重要原料。無色且具腐蝕性。
    • 受光線照射會分解出紅棕色、有毒的氣體，使溶液呈淡黃色。因此必須裝在玻璃瓶中並避光保存。
    • 活性極強，可與銅、銀反應。銅與稀硝酸反應產生無色的；銅與濃硝酸反應產生紅棕色有毒的。
    • 王水：由濃硝酸與濃鹽酸以體積比 混合而成，可溶解活性極小的和鉑。
  4. 醋酸 (CH₃COOH)：
    • 學名。易溶於水，但水溶液中不易解離，屬於酸、電解質。
    • 食醋中約含有 % 的醋酸。
    • 純度 99.5% 以上的醋酸在 16.7°C 時會凝固成固態，外觀像冰，俗稱。純醋酸因無法解離出氫離子，呈性。

【主題 3 常見的鹼】

  1. 氫氧化鈉 (NaOH)：
    • 白色固體，水溶液摸起來有滑膩感，因具強腐蝕性俗稱，又因溶於水會放出大量熱而稱。
    • 在空氣中極易吸收水氣而變潮濕，此現象稱為。
    • 也容易吸收空氣中的形成碳酸鈉而變質，因此必須存放在乾燥的密閉容器中。
    • 常用來製造、紙張及廚房去油汙清潔劑。
  2. 氫氧化鈣 (Ca(OH)₂)：
    • 白色粉末，俗稱。微溶於水，水溶液俗稱。
    • 澄清石灰水可用來檢驗，通入後會生成白色的混濁沉澱物。
    • 將 (CaO，俗稱生石灰) 溶於水中會放熱並產生氫氧化鈣。氧化鈣因易吸水，常作食品包裝內的。
  3. 石灰的循環關係：
    (1) 灰石 / 石灰石 (化學式：) ——→ 生石灰
    (2) 生石灰 / 石灰 (化學式：) ——→ 熟石灰
    反應式： CaO + H₂O → + 熱
    (3) 熟石灰 (化學式：) ——→ 石灰水
    (4) 石灰水 ——→ 灰石 (產生白色混濁沉澱)
    反應式： Ca(OH)₂ + CO₂ → H₂O + ↓
  4. 氨 (NH₃)：
    • 無色、具有味的氣體，密度比空氣。急救：若工廠氨氣外洩，常向空中灑以吸收氨氣。
    • 乾燥氨氣及液態氨呈性；氨氣溶於水俗稱 (阿摩尼亞)，呈性。
    • 稀釋後的氨水可消腫止癢 (因蚊蟲唾液含有)，並可作家庭清潔劑。
    • 氨與二氧化碳作用可生成，用來製造肥料。
    • 噴泉實驗：將裝有氨氣或氯化氫氣體的燒瓶倒置於水中。因為氣體極，溶解後燒瓶內壓力外界大氣壓力，水被壓入燒瓶形成噴泉。若下方燒杯水中有加酚酞，氨水噴泉會呈現色。
    • 健康警訊：檳榔中間通常添加，嚼食後呈性會傷害口腔，易引起細胞病變引發口腔癌。

【主題 4 經典與素養試題觀念釐清】

  1. 除垢原理：電熱水瓶內壁常附著含碳酸鈣和碳酸鎂的鍋垢，應使用微酸性的或浸泡去除。
  2. 純乙酸的物態：純乙酸液體在25℃環境下逐漸冷卻，若有固體出現並沉於杯底，代表其凝固點（熔點）25℃（實際約為16.7℃），且因沉於杯底，可知固態密度液態密度。
  3. 虎門銷煙：將鴉片引入浸泡池後加入石灰（生石灰 CaO）。因石灰溶於水為反應，產生的高溫能使鴉片更易溶於水中。
  4. 膨脹劑反應：製作麵食使用的膨脹劑 (NH₄)₂CO₃，加熱分解會產生 CO₂、H₂O 以及一種具有刺激性臭味的氣體，該氣體為。
  5. 化學試劑溶解安全：次氯酸鈣（漂白劑成分）溶於水會產生高溫。為避免氣爆，混合步驟應如同稀釋濃硫酸，必須將緩緩加入中。
  6. 金屬與酸反應計量：甲、乙兩種不同的金屬與同濃度鹽酸完全反應。若產生的氫氣(H₂)質量相同，則消耗的鹽酸質量必定，但因甲乙原子量不同，產生的金屬氯化物總質量則會。
